# Feature Flags (sd.featureflag)

Модуль управления функциональностью системы через фича-флаги для 1C-Bitrix (коробка).  
Позволяет включать и отключать отдельные части функционала без изменения кода и деплоя.

## Возможности

- Включение/отключение функциональности через UI
- Поддержка глобальных флагов
- Ограничение по:
    - пользователям
    - группам
    - сайтам
- Централизованное управление
- Быстрое отключение проблемных фич
- Поддержка постепенного rollout

## Зачем это нужно

Модуль решает типовые проблемы разработки:

- Выкатка фич без риска
- Возможность скрыть незавершённую функциональность
- Быстрый rollback без деплоя
- Управление доступом к новым возможностям
- Подготовка A/B тестов

## Пример использования

```php
use Sholokhov\FeatureFlag\Feature;

if (Feature::isEnabled('crm.application.v2')) {
    // Выполняем новую логику
    $this->newLogic();
} else {
    // Выполняем старую логику
    $this->oldLogic();
}
```

## Рекомендации по использованию

- Всегда оставляйте fallback (старую логику)
- Удаляйте флаг после полного rollout
- Используйте осмысленные коды:

```
crm.order.new_detail
calendar.events.permissions_v2
application.auto_moderation
```

## Кеширование

Модуль использует кеширование для оптимизации:

- все флаги
- флаг по коду
- флаг с учетом пользователя

Сброс кеша происходит при изменении флага через UI.

## Управление

Флаги управляются через административный интерфейс

## Расширение

Модуль легко расширяется:

- добавление новых типов scope
- интеграция с внешними системами
- реализация A/B тестирования
- добавление rollout по проценту пользователей
